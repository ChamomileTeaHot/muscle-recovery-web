# 리커버리

운동 후 스트레칭을 찾고, 식사·운동 기록을 함께 살펴보는 웹앱입니다. [앱 열기](https://muscle-recovery-guide.f79c69e9-1f74-440a-9ff2-cd1bead424d3.chatgpt.site/)

## 주요 기능

- 운동 876개를 한국어·영어로 검색하고 사진과 사용 근육을 확인합니다.
- 근육이 겹치는 정적 스트레칭 후보를 고르고 방법을 볼 수 있습니다. 추천 점수는 실제 근육 부하나 회복률이 아닙니다.
- 날짜별 운동 횟수와 스트레칭 여부를 기록합니다. 로그인하지 않으면 해당 브라우저에, 로그인하면 계정에 저장합니다.
- 완제품 중심으로 전처리한 음식 13,026개를 검색해 날짜·끼니별 섭취량과 영양값을 기록합니다. 식사 기록은 해당 브라우저에 저장됩니다.
- 성인용 음식·운동 변화 화면은 기초대사량, 활동계수, 운동 유형·시간을 조합해 하루 열량 차이와 최대 4주의 산술 체중 시나리오를 보여줍니다. 하루 열량 차이가 크면 그래프 계산값을 ±1,000kcal로 제한합니다. 실제 체중이나 근육량의 예측은 아닙니다.
- 만 5세 1개월부터 17세 11개월까지는 키·BMI 성장 위치가 유지된다고 가정한 성장 참고선을 보여줍니다. 음식·운동 열량을 미성년자의 체중 변화로 환산하지 않습니다.

운동 기록을 다른 기기와 동기화하려면 계정 로그인이 필요합니다. 로그인하지 않고 저장한 기록은 그 기기에만 남습니다. 식사 기록도 기기 간 동기화되지 않습니다.

## 실행

Node.js 22.13 이상과 pnpm이 필요합니다.

```sh
pnpm install
pnpm dev
```

검증 명령:

```sh
node --experimental-strip-types --test tests/*.test.mjs
pnpm exec tsc --noEmit
pnpm build
```

## 데이터와 계산

운동·스트레칭 자료는 제공된 근육 회복 프로그램 노트북과 Free Exercise DB를 바탕으로 구성했습니다. `public/data/`에 검색용 자료가 있고 `public/images/`에는 화면용 WebP 사진이 있습니다. 자료의 출처와 사용 조건은 [LICENSE.source.md](LICENSE.source.md)를 확인하세요.

음식은 사용자가 정정해 제공한 CSV 14,584개 항목에서 소스·양념·원액 26개와 구성 재료·세부조건 항목 1,532개를 제외했습니다. 최종 목록은 `public/data/foods.json`과 `foods-preprocessed.csv`에 있으며, 제외 사유는 `lib/food-source.json`에 보존했습니다. 100g과 100ml의 원본 기준량을 유지하고 결측 영양값을 임의로 채우지 않습니다.

성인 시뮬레이션은 사용자가 만든 비만 예방 프로그램의 기초대사량 식과 BMI 식을 사용합니다. 운동 추가 소비는 `(MET − 1) × 체중(kg) × 시간(h)`, 체중 시나리오는 `하루 열량 차이 × 일수 ÷ 7,700`으로 계산합니다. 같은 하루의 입력이 반복된다는 단순 가정이며, 성장·수분 변화·대사 적응·체성분 변화를 반영하지 않습니다. 의료적 판단이나 식단 처방에 사용하지 마세요. 계산 근거와 관련 자료 링크는 앱의 그래프 화면에 있습니다.

## 주요 파일

- `app/recovery-app.tsx`: 운동 검색과 스트레칭 흐름
- `app/workout-panel.tsx`, `lib/workout-storage.ts`: 운동 기록과 저장 방식
- `app/nutrition-panel.tsx`, `lib/nutrition.ts`: 식사 입력과 영양 합계
- `app/body-trend-panel.tsx`, `lib/body-trend.ts`: 성인용 변화 시나리오
- `app/youth-growth-panel.tsx`, `lib/youth-growth.ts`: 어린이·청소년 성장 참고선
- `scripts/prepare-foods.py`: 음식 자료 전처리
