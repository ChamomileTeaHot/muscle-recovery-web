# 리커버리 — 운동 후 스트레칭 웹앱

첨부된 `근육_회복_프로그램_데모.ipynb`의 최종 내장 데이터와 추천 로직을 웹 인터페이스로 옮겼습니다.

## 기능

- 운동 876개: 한국어·영어 검색, 부분 일치와 오타 후보 안내
- 운동 사진과 사용 근육 확인 → 스트레칭 선택 → 한국어 방법과 사진
- 기본 정적 스트레칭 30개에서 보유 도구·추천 개수로 후보 선정
- 주동근/보조근 일치 4·2·1점, 새로운 근육을 다루는 후보 우선
- 도구가 없거나 후보가 없는 근육은 별도 안내
- 모바일 레이아웃, 키보드 조작, 사진 확대, 이미지 누락·데이터 오류 처리

계정·운동 기록 저장·치료 처방·실제 근육 부하 계산 기능은 없습니다. 검색과 추천은 브라우저 내부에서 처리합니다. 일반 운동 상세 설명 753개는 영어 원문을 보존했습니다.

## 개발

Node 22.13 이상과 pnpm을 사용합니다.

```sh
pnpm install
pnpm dev
node --experimental-strip-types --test tests/recovery.test.mjs
pnpm exec tsc --noEmit
pnpm build
```

`lib/recovery.ts`는 검색·추천 로직이며 `app/recovery-app.tsx`는 화면입니다. `public/data/`는 노트북에서 추출한 데이터, `public/images/`는 기존 사진을 화면용 WebP로 변환한 파일입니다. 외부 사진 API나 사용자 ZIP 업로드가 필요 없습니다.

`scripts/extract-notebook.py`는 노트북의 상수만 읽어 압축된 JSON을 추출하며 셀 코드를 실행하지 않습니다. 최종 노트북 함수가 기존 참조 함수와 동일함을 확인했고, 44가지 입력에서 웹 추천 결과가 Python 참조 결과와 일치하는 것을 검사했습니다. 원본 출처의 해시는 `lib/notebook-source.json`에 기록했습니다.

원본 데이터의 분류를 그대로 사용하므로 해부학적 정확성이나 개인별 적합성에 대한 임상 검증을 뜻하지 않습니다. 추천 점수는 실제 부하·근활성도·회복률이 아닙니다.

기본 추천 목록과 번역 내용의 변경은 별도 데이터 검토가 필요합니다. 데이터 사용 조건은 함께 보존한 원본 라이선스를 확인하세요.
